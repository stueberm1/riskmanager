interfaces::

The risk-manager-core provides an incoming port as access-point for clients called `risk` and requires an outgoing port called `persistence`.

While the risk-manager-core is responsible to provide everything to fulfill the contract (risk), the requirement (persistence) must be realized in the specified way by a suitable service provider, which needs to get injected by the overall system.
