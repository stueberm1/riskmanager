== Resources

[[model-risk-json]]
=== /risk

.Description of the risk
[cols="2a,1, 1a,2" options="header"]
|===
|Property                   | Type      |Constraints                                        | Description
|__id__                     |number     |integer; stem:[id > 0]                             | Unique identifier of a risk defined by the api-client. It **must** be an integer value greater then zero and __should__ be a number from a sequence.
|__severity__               |string     |enum; not null                                     | Abstract severity if the the risk becomes a problem.
|__probabilityOfOccurrence__|string     |enum; not null                                     | Abstract probability the risk becomes a problem
|__description__            |string     |not null; stem:[10 <= description.length() <= 50]  | Short description of the risk
|__details__                |string     |not null; stem:[description.length() > 0]          | Details of the risk, so that all project stakeholders can understand and assess the risk.
|__contingencyPlanning__    |string     | optional                                          | If available, a plan what to do, if the risk becomes a problem
|__mitigationStrategy__     |string     |optional                                           | If available, some Ideas to reduce the probability the risk becomes a problem
|===

[[model-problem-details]]
=== ProblemDetails

In case of exceptions in processing of <<model-risk-json, risks>> the problem details the problem details contains
more specific details about the problem then having only the http status codes as described in https://www.rfc-editor.org/rfc/rfc9457.html[RFC 9547].

The details allows clients to handle and fix the problem.

The api extends the default elements with additional with a n optional list of Error details. This allows to point to describe
the problem down to single attributes.

.Description of the ErrorDetails
[cols="1a, 2" options="header"]
|===
| Property      | Description
|__details__    | Details on the constraint that caused the problem
|__pointer__    | A JsonPointer as specified in https://datatracker.ietf.org/doc/html/rfc6901[RFC 6901] pointing to the attribute that caused the problem.
|===

The types used for presenting problem details are documented in the xref:problems/index.adoc[Problem-types catalog].
